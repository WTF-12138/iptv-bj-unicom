# 北京联通 IPTV 播放列表（自动更新）

北京联通 IPTV 的家用组播播放列表。由自建软路由**每日自动探活、检测到地址变化即推送更新**。个人自用为主，公开留档，碰到能用便用。

## ⚠️ 使用前必读

- **仅在北京联通 IPTV 城域网内可用**：列表里是 `239.x.x.x` 组播地址，只在北京联通宽带/IPTV 网络内可达。**公网、外省、其他运营商拿到也放不了。**
- 需支持组播（RTP/TS）的播放器；建议 **单网口设备**——双网口主机常因网口问题收不到组播（是网口问题，非地址问题）。
- 播放器 URL 用 `rtp://@组:端口`（写成 `udp://@` 会花屏）。
